  • 高波動事件驅動的題材型波段股，常在事件 AVWAP、短線VWAP與長均線之間快速重估，急漲後回撤幅度大

  • 市場定位：觸控玻璃 / 車載顯示 / 光電材料
  • 非屬類型：不可把高振幅直接等同高beta；高當沖、融資與借券共振時，需防假突破、滑價與深回撤

  • A 級核心主線：短線方向由65.0~66.0成本帶與67.9~68.4短壓決定
  • A / B 級交會主線：事件 AVWAP 74.2與主 AVWAP 86.7未收復前，只能視為反彈壓力
  • 題材重評主線：量曲線正式預設20日窗口；60日樣本不足不得升級信心
  • 中長線補充主線：法人買超需與價格、量能及成本帶收復同時確認，不能單獨視為主力鎖籌

  • C 級：族群輪動、媒體敘事、低成長或低毛利舊業務，不能取代 A 級主線
